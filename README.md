# GOLDAnaBAlKE — Магазин компьютерной техники и периферии

Тема: **«Адаптивная вёрстка и доступность многостраничного сайта интернет-магазина с пользовательским интерфейсом на React»**.

## 1. Архитектура проекта (HTML + чистый CSS + JS-логика + React UI)

Проект разделён на независимые слои без использования CSS-фреймворка Bootstrap:

1. **Пользовательский интерфейс на React 18 (`js/components-shell.js`, `js/components-pages.js`):**
   - единая шапка сайта и адаптивная навигация на 4 основных раздела (**Главная**, **Каталог**, **О магазине**, **Контакты**);
   - интерактивный **Личный кабинет покупателя** с тремя вкладками (*«Профиль»*, *«Избранное»*, *«Мои заказы»*);
   - реактивная система **Избранного** (сердечки на карточках и странице товара + счётчик в шапке);
   - **живой поиск по каталогу**, фильтрация по категориям, наличию и диапазону цен, сортировка по стоимости;
   - **интерактивный калькулятор заказа** с выбором способа получения и сервисных опций;
   - **стилизованная капсула «Наверх» справа** с круговым индикатором прогресса прокрутки (`0–100%`) без использования стрелки;
   - трёхколоночный **футер с логотипом, слоганом, копирайтом, иконками разделов и контактных данных**.
2. **Бизнес-логика на чистом JavaScript (`js/logic.js`):**
   - единое хранилище состояния с реактивной подпиской компонентов и синхронизацией с `localStorage`;
   - расчёт стоимости комплекта и сервисных опций, сохранение истории заказов, избранного, профиля и чек-листа.
3. **Адаптивная стилизация на чистом CSS3 (`css/style.css` + `css/responsive.css`):**
   - подход **Mobile First** (`@media (min-width: 430px)`, `640px`, `768px`, `900px`, `1024px`, `1280px`, `1440px`);
   - глубокая индиго-палитра с поддержкой переключения светлой и тёмной темы (`[data-theme="dark"]`);
   - адаптивные изображения (`<picture>`, `srcset` `480w / 800w / 1200w`, `sizes`, `loading="lazy"`) и адаптивные таблицы характеристик в контейнере `.table-wrapper` (`overflow-x: auto`).

## 2. Структура проекта

```text
kr3-responsive-shop/
├── index.html                  # Главная страница (Hero с <picture>, направления, хиты недели)
├── catalog.html                # Каталог с живым React-поиском, сортировкой, фильтрами и избранным
├── about.html                  # О магазине (демо-зона, цифры, преимущества, карусель отзывов, FAQ)
├── contacts.html               # Контакты (магазины в Москве, каналы связи, карта, форма обратной связи)
├── product.html                # Страница устройства (переключатель товаров, таблица в .table-wrapper, чек-лист)
├── order.html                  # Калькулятор стоимости заказа с сохранением в Личный кабинет
├── css/
│   ├── style.css               # Дизайн-система GOLDAnaBAlKE, компоненты, темы и модальные окна
│   └── responsive.css          # Адаптивная сетка Mobile First (min-width медиазапросы)
├── js/
│   ├── vendor/                 # Локальные сборки React 18 и ReactDOM 18
│   ├── logic.js                # Чистая JS-логика, расчёты калькулятора и хранилище localStorage
│   ├── components-shell.js     # React-компоненты шапки, футера, кнопки «Наверх» и Личного кабинета
│   └── components-pages.js     # React-компоненты каталога, карточек, калькулятора, отзывов и FAQ
├── images/                     # Логотип и адаптивные фото техники (480w, 800w, 1200w)
├── README.md                   # Документация проекта
└── .gitignore                  # Исключения Git
```

## 3. Проверенные контрольные ширины (DevTools)

- `360px` — компактный смартфон (одноколоночная сетка, бургер-меню, отсутствие горизонтального скролла);
- `430px` — крупный смартфон (кнопки действий в ряд, раскрытые подписи);
- `768px` — планшет (сетка карточек в 2 колонки, форма заказа в 2 колонки, `sticky`-шапка);
- `1024px` — ноутбук (горизонтальная навигация, двухколоночный каталог с `sticky`-фильтром, 3 колонки футера);
- `1440px` — широкий монитор (центрированный контейнер до `1340px`, 3 колонки карточек в каталоге).

## 4. Локальный запуск и опубликованная версия

Для локального запуска выполните в корне проекта:

```bash
python3 -m http.server 8090
```
