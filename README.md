# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина компьютерных аксессуаров **ShopProject**, выполненную по дисциплине «Фронтенд и бэкенд разработка» без использования CSS-фреймворков (Bootstrap).

## Описание адаптивных решений

- **Подход Mobile First:** базовые стили в `css/responsive.css` ориентированы на узкие мобильные экраны от `360px`, а усложнение раскладки выполняется через `@media (min-width: 480px)`, `640px`, `768px`, `900px`, `1024px`, `1200px` и `1280px`.
- **Контейнеры и секции:** используется единая адаптивная ширина `width: min(100% - 32px, 1200px)` и гибкие вертикальные отступы через `clamp()`.
- **Навигация и sticky-шапка:** на мобильных экранах шапка остаётся в обычном потоке (`position: static`), а ссылки меню выстраиваются вертикально с удобной областью нажатия. Начиная с `768px` шапка закрепляется (`position: sticky; top: 0; z-index: 100`), а `scroll-padding-top` предотвращает перекрытие заголовков при переходе по якорям.
- **Адаптивные изображения:**
  - в первом экране `index.html` используется `<picture>` с тремя версиями коллажа товаров (`640×480`, `960×720`, `1280×960`);
  - в карточках товаров на главной, в каталоге и на страницах товаров используются `srcset` (`480w`, `640w`, `1000w`), `sizes`, `aspect-ratio: 4 / 3`, `object-fit: cover` и `loading="lazy"`.
- **Формы и модальное окно:** поля ввода имеют `min-height: 44px`, на мобильных экранах располагаются в одну колонку, а от `768px` перестраиваются в двухколоночную сетку с полноширинными блоками `.order-form__field--wide`. Модальное окно ограничено по ширине `min(100% - 32px, 560px)` и высоте `calc(100vh - 32px)` с внутренней прокруткой.
- **Таблицы характеристик:** обёрнуты в `.table-wrapper` с `overflow-x: auto` и `-webkit-overflow-scrolling: touch`, благодаря чему таблица прокручивается внутри своего блока и не вызывает горизонтального скролла страницы.

## База проекта (КР №1 — практики №1–8)

В основе проекта лежит многостраничный учебный интернет-магазин `ShopProject`:
- семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `dialog`, `details`/`summary`);
- именование CSS-классов по методологии БЭМ (`site-header`, `site-nav`, `hero`, `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `product-details`, `product-table`, `order-form`, `order-dialog`, `faq`, `to-top`, `site-footer`);
- клиентская валидация формы заявки в `js/main.js` через `checkValidity()` с выводом ошибок в связанные через `aria-describedby` элементы и управлением модальным окном `<dialog>`.

## Как запустить и проверить локально

Сборка и внешние зависимости не требуются. Для запуска локального сервера выполните в папке `kr3-responsive-shop`:

```bash
python3 -m http.server 8080
```

После запуска откройте `http://localhost:8080` в браузере и проверьте отображение страниц в Chrome DevTools на ширинах `360px`, `430px`, `768px`, `1024px` и `1440px`.
